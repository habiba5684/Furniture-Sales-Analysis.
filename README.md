# 🪑 Furniture Sales & Profitability Analysis

## 📌 Project Overview
This project focuses on analyzing furniture sales data to understand sales performance, profitability, customer segments, regional performance, and shipping efficiency.

Using Python and Exploratory Data Analysis (EDA), the project explores numerical and categorical features to identify sales patterns, evaluate business performance, and uncover potential areas for improvement.

## 🎯 Project Objectives
- Analyze total revenue, profit, quantity sold, and number of orders.
- Calculate profit margin and average order value.
- Explore the relationship between sales and profit.
- Identify the orders with the lowest profits.
- Compare sales performance across different regions.
- Identify the best-performing product sub-categories.
- Analyze monthly sales trends.
- Explore sales across states and customer segments.
- Compare shipping modes based on average delivery duration.
- Evaluate profitability across regions.

## 📈 Key Performance Indicators (KPIs)
The analysis calculates the following metrics:

- **Total Revenue:** Overall sales generated.
- **Total Profit:** Overall profit or loss.
- **Total Orders:** Number of unique orders.
- **Total Quantity Sold:** Total units sold.
- **Profit Margin:** Profit as a percentage of revenue.
- **Average Order Value (AOV):** Average revenue per unique order.
